# Original academic code

The R script is the byte-preserved Spring 2026 MAT 429 submission by Youssef Rafik. The corresponding [academic report](../reports/original_report.pdf) is preserved as submitted. To rerun the original script, use a scratch directory containing copies of both the script and the authorized CSV, then run `Rscript MAT429_final_project_code.R` with dplyr and ggplot2 installed. The script expects its CSV in the current directory.
